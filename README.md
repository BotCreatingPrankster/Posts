## How this repo works

| Path | What's in it |
|---|---|
| `ideas.md` | Running list of post ideas, one line each |
| `drafts/` | Work in progress. Start each one by copying `templates/post.md` |
| `published/` | Final text of posts that went live, named `YYYY-MM-DD_short-slug.md` (the date it was posted) |
| `templates/post.md` | Standard structure for a LinkedIn post |

Each post starts with a header block (`date`, `topic`, `status`, `linkedin_url`).
